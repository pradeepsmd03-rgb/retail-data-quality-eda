# Retail Sales: Data Quality & Exploratory Data Analysis

**Internship milestone:** 2. Data Quality and Exploratory Analysis
**Tools:** Python, pandas, NumPy, Matplotlib, Seaborn

An end-to-end workflow: audit a messy dataset, clean it with documented decisions, then explore it to find business insights.

## Dataset
`data/raw_sales.csv` holds 5,080 retail orders (11 columns): order date, customer, category, region, payment method, unit price, quantity, discount, customer age, and total amount.

The data is **synthetic**, generated by `src/generate_data.py` with a fixed random seed so results are reproducible. Realistic quality problems were injected on purpose so the cleaning steps can be demonstrated. To use real data, replace `data/raw_sales.csv` with your own file that has the same columns.

## 1. Data quality audit

| Issue | Found | Treatment |
|---|---|---|
| Duplicate rows | 80 | Dropped |
| Invalid dates (e.g. 31/02/2024) | 30 | Rows dropped (date is essential) |
| Negative quantities | 26 | Rows dropped (invalid orders) |
| Impossible ages (<18 or >100) | 30 | Set to missing, then imputed with median |
| Missing `customer_age` | 253 | Median imputation |
| Missing `region` | 149 | Filled with `"Unknown"` |
| Missing `payment_method` | 101 | Filled with `"Unknown"` |
| Inconsistent category labels (`books` vs `Books`) | 12 labels -> 6 | Standardised to title case |
| Whitespace in `region` (`" North "`) | 5 labels -> 4 | Trimmed |
| Extreme price outliers | 20 | Removed using 3 x IQR rule per category |

**Result:** 5,080 rows -> 4,925 rows (about 3% removed). `total_amount` was recomputed from price, quantity and discount for consistency.

## 2. Key findings from EDA

1. **Electronics drives revenue.** It brings in about 1.36M of 2.58M total (~53%), followed by Home & Kitchen (~18%). Books contribute only ~2%.
   ![Revenue by category](outputs/figures/02_revenue_by_category.png)
2. **Revenue is fairly flat across the year.** Monthly revenue ranges from about 182K to 255K, peaking in March and dipping in August and November, with no strong seasonality.
   ![Monthly revenue](outputs/figures/03_monthly_revenue.png)
3. **Order value is right-skewed.** The median order is about 242, but the mean is about 523, pulled up by a few high-value electronics orders.
   ![Order value](outputs/figures/04_order_value_distribution.png)
4. **Unit price is the main driver of order value** (correlation 0.85). Quantity matters less (0.32).
   ![Correlation](outputs/figures/07_correlation.png)
5. **Discounts show no clear volume lift.** Average quantity stays around 4 whether the discount is 0% or 20%, so discounts reduce revenue per order without raising units sold. *(Caveat: this is correlation on a synthetic sample, not a causal test.)*
6. **Customer age has almost no effect** on spending. Average order value is similar across age groups, slightly lower for ages 56+.
7. **Payment methods are evenly split** (~24-25% each), and the region x category mix is balanced.
   ![Heatmap](outputs/figures/06_region_category_heatmap.png)

## 3. Recommendations
- Protect and grow Electronics. It is the main revenue source.
- Review discount strategy, since heavy discounts show no volume benefit in this data.
- Add input validation at data entry (date formats, positive quantities, age ranges, dropdown categories) to prevent the issues found in the audit.
